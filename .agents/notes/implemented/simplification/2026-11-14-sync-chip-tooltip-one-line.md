# Agent Note: 页头那枚同步状态的悬浮提示缩成一句

Status: implemented

## Problem

那枚按钮的悬浮提示原来按"按钮干什么 · 为什么是这个颜色"拼第一行，后面最多再跟三行「没做到」的
原话与一句「还有 N 条」，最长五行。第一行本身就是两个从句用 `·` 接起来，比如自动同步那一档：

> 打开同步：远端、计划、差异与确认 · 自动同步开着：写完一轮、安静 5 分钟之后双向对齐，并顺手整理自己那一格

一句 54 个字，说的却是两件事：按钮点开是什么、自动同步怎么跑。后半句在弹窗里一字不差地又说了一遍
（「自动同步已开：写完一轮、安静 5 分钟之后双向对齐，并整理自己那一格。」）。"没做到"那几行同理：
弹窗里那张「上次同步」列全、还带「只看这一条」。

同一枚按钮上还有第二层提示：鼠标落在那个 10px 的点上是另一句（「自动推送开着：…」/「上次同步没成：
401 Unauthorized」）。两层说法不一样，落点只差几个像素；而失败原因只挂在点上——鼠标停在按钮其余
部分反而看不到"为什么红了"。

## Decision

**一枚按钮一层提示，只有一句。**

- 提示就是这一档的一句话：`正在同步` / `上次同步失败：401 Unauthorized` / `上次同步失败（记录里
  没有原因）` / `上次同步有 2 条没做到` / `上次同步的改动要重启 DSH 才生效` / `自动推送已开` /
  `自动同步已开` / `还没配置远端`；干净、没跑过就**连提示都不出**。
- 不再交代"这个按钮干什么"（原来那句「打开同步：远端、计划、差异与确认」）：按钮的文字「同步 ·
  3 小时前」与它在页头的位置已经说明它是什么，点开只是一步。
- **"没做到"的原话不再进提示**：提示只报条数，名单留在弹窗里那张「上次同步」（还带「只看这一条」）。
- **红点那份原因搬到按钮上**：不再只有 10px 的点说得出"为什么红了"。
- **点不再单独挂提示**：删掉 `.dsm-dotSlot` 外面那层 `Hint`，也删掉 `sync.chip.dot.*` 那组键。
  颜色仍然有一句理由——就是这句提示。

## Alternatives considered

- **保留两级，只把句子改短**：10px 的命中区实际很少有人专门悬上去，两套说法还要各自维护；而两层
  说法的差别（"这个按钮干什么" vs "这个颜色什么意思"）用户并不关心。
- **保留前三条原话**：一行一条会话名 + 路径，实测 40 字上下；三条加上去比按钮本身还高。真要看名字
  的场合是"处理它"，那正是弹窗。
- **只把自动同步那句改短**：其余几档仍然是"动作 + 理由 + 名单"混在一格里，问题还在。
- **用浮动面板代替 `title`**：要管展开、收起、点外面关闭，为一句状态引入一套交互不划算。

## Consequences

- 悬停一眼读完：只有一句、≤ 20 字；没有要说的事就不出提示，不再出现 54 字的复合句。
- 失败原因第一次在按钮本身上说得出来（原来只在点上）。
- 少一次"悬停 → 读三条 → 再点开"的往返；代价是看不到具体哪几条，要多点一下——明细在弹窗里列全。
- 字典里删掉 `sync.chip.dot.*`（8 个键）与 `sync.chip.moreLeftovers`，新增 7 个 `sync.chip.note*`；
  中英两份同进同退。
- 判据仍在 `logic/syncChipDot.ts` 的纯函数里：`syncChipDot()` 管颜色，`syncChipNote()` 管这句短话；
  `test/sync-chip-dot.test.ts` 把每一档都钉了一条。
