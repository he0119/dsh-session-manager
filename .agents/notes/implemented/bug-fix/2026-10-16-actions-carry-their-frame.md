# Agent Note: 动作行里的动作带边框

Status: implemented

## Problem

卡片底部那条动作行（`.dsm-controls`）里并排的动作全走官方 `Button` 的**缺省**变体 `ghost`。真实
dev GUI 里量到它们：

```
color: rgb(15, 17, 21)          /* 文字色倒是正文色 */
background-color: rgba(0, 0, 0, 0)
border-width: 0px
```

无边框、无底色，一条动作行看过去就是一段灰字；没有勾选时还叠加官方禁用态的 `opacity: 0.4`，更像一段
说明文字——分不出哪几处能点。同一屏里内建设置页那枚**只读**动作「打开配置文件」反而带边框
（`outline`，`border: rgba(0, 0, 0, 0.12) 1px`、圆角 8px、28px 高）。

原来的口径写在注释里：**"动数据 → 非 ghost，不动数据 → ghost"**。「测试连接」「丢弃草稿」都按这条走
了 ghost，可内建那枚同样只读的「打开配置文件」是有边框的——官方并不按"写不写盘"分。

## Decision

**这一页不用官方缺省的 `ghost`**：凡是用官方 `Button` 的地方都给边框——主动作 `primary`（同步 / 导出 /
导入 / 弹窗的确认，原来就是），其余 `outline`。这一条不按"它自己写不写盘"分，也不按"它是动作还是工具"
分：卡头的刷新 / 全选 / 清空 / 收起展开与横幅上的关闭都算进来，因为只要它还裸着，"鼠标放上去才知道是
按钮"这件事就还在。

边框由官方 `Button` 自己画（`outline` 用的是它自己的 `border-l3`），本页 CSS 仍然只写布局——那条
"控制件一律用官方原语"的硬约束没有松动，改的只是**选哪个变体**。

两个**手写**的文字动作仍在例外，它们按行内链接 / 图标画、外观由本页 CSS 给（官方原语不管行内链接）：

- 每行右端那枚「内容」（`.dsm-rowInspect`）：悬停或聚焦才显形，触屏常显，hover 有下划线；
- 分组头那枚开合图标 ▾（`.dsm-groupToggle`）：20×20 的图标钮，hover 有底色。

## Alternatives considered

**沿用"写不写盘"那条口径。** 内建那枚只读的「打开配置文件」正是带边框的，按这条口径它应该是 ghost；
这条口径解释不了量到的事实。

**本页自己给 ghost 画边框。** 违反"控制件用官方原语"（`styles.ts` 只写布局挂钩），而且官方换一版就
得再抄一遍。

**只给"会动数据的动作"边框，工具保持裸着。** 这条口径先落过一次（动作行那五枚 + 同步设置表单那几枚），
真机上看仍然不对：卡头那一行「按目录分组 / 全部收起 / 全部展开」并排看还是三个词，鼠标放上去才知道能
点——"工具"与"动作"在用户这边没有区别，裸着就是看不出是按钮。

**自己给 ghost 画边框。** 违反"控制件用官方原语"，而且官方换一版就得再抄一遍。

## Consequences

- 动过 11 个组件、33 枚按钮：会话页那五枚动作与卡头的全选 / 清空 / 收起 / 展开、同步页动作行里的
  「立即推送」、同步设置表单的加一行 / 测试连接 / 丢弃草稿 / 删掉一行映射、候选目录面板与目录浏览框的
  工具与取消、目录字段的手输路径 / 收起、备份页的刷新与每行的恢复 / 回滚、横幅上的关闭、会话内容弹窗的
  查看全文（传输页动作行那两枚本来就是 `primary`，没动）。
- 规格由 `test/client.test.mjs` 钉住：把四个分页的树整棵走一遍，官方 `Button` 的变体**一个都不许**是
  缺省 `ghost`（认的是假原语渲染出来的 `data-variant`，所以没写 `variant` 的按钮也算进来——它们正是
  要抓的那一类）；另外动作行不能是空的（动作要有地方站）。
- 判据认的是假原语渲染出来的 `data-variant`，所以**没写 `variant` 的按钮也算进来**——它们正是这一条
  要抓的那一类。
