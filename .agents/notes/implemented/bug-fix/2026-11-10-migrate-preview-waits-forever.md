# Agent Note: 勾中的会话都搬不走时，迁移弹窗不再停在「预演中…」

Status: implemented

## Problem

「会话」页勾上一条**已归档**的会话，点「迁移」：目标目录已经选好，弹窗却一直停在「预演中…」，确认按钮
禁用，等多久都不会变。

原因不是慢，是那份计划**根本没有发出去**：

- 这一页只把侧边栏看得见的会话送进迁移计划（`migratable`，判据是 `/state` 的 `hidden`，见
  [迁移排除侧边栏不显示的会话](../architecture/2026-09-28-migration-excludes-what-the-sidebar-hides.md) 与
  [会话页那一枚迁移](../architecture/2026-10-13-source-is-what-you-tick.md)）。
- `runPreview()` 在 `migratable.length === 0` 时直接返回（不去取计划）。
- 而"预演中"的判据只看 `response` 与 `error` 都是 `null`——两个都还是 `null`，于是那句等待一直留着。

真发出去的话快得很：拿同一条已归档会话打 `POST /migrate`（`mode: 'plan'`），宿主 2.4 秒回一份"迁移 0 个
会话 + 问题 1 项（archived）"的计划。所以这个死胡同与网络、与扫描速度无关，是空集合这一支没有对应的
界面状态。

## Decision

弹窗里多认一种状态：`nothingMigratable`（勾中的一条都搬不走）。

- 「预演中…」不再出现（`planning` 里加上 `!nothingMigratable`）；
- 正文换成一句 `migrate.nothingVisible`：勾中的都侧边栏不显示、这次没有可迁移的会话、先在列表里单独处理
  （取消归档 / 删掉空白 / 子智能体连着父会话一起迁）；
- 底部那句「另有 N 条勾中的会话侧边栏不显示」只在**部分**隐藏时出现——全隐藏时上面那句已经把话说完了，
  两句话并排只是重复。

## Alternatives considered

- **点「迁移」时不弹窗、只在页面顶部报一句。** 那枚按钮离页面顶部远，用户刚点完看不到说明；弹窗就开在
  点击的位置，说明摆在那里最容易被读到。
- **把隐藏的那些也送进计划，让宿主回"拒"。** 为一份不可能落地的计划白扫一遍整库（1.2 秒），而且计划里
  那条问题对"已归档"这种用户自己能修的事没有指导性——修法是取消归档，不是改目标目录。
- **「迁移」按钮在空集合时直接禁用。** 禁用而没有解释比现在更差：这一页本来就是用来收拾隐藏会话的
  （取消归档、删空白），用户需要知道"为什么不能迁"，而不是一个点不动的按钮。
- **让 `runPreview()` 在空集合时塞一个错误。** 那会把"没有可迁的"说成"预演失败"，错误横幅与问题清单都会
  被引到一条不存在的失败上。

## Consequences

- 勾中的都搬不走时，弹窗显示一句说明、确认按钮禁用，不再有永不结束的等待。
- 部分搬不走时行为不变（照旧只送看得见的进计划，底部说"另有 N 条"）。
- 新增一条界面文案 `migrate.nothingVisible`（中英各一条）；`test/client.test.mjs` 钉住"这一态不出现
  `dialog.previewing`、出现新文案、确认按钮禁用"。
