# Agent Note: 选行工具全站只有一对（全选 / 清空）

Status: implemented

## Problem

三张带勾选的清单各有一套选行语法，同一件事（"这几条我都要 / 都不要"）在界面上是三种形状：

- **会话页**：卡头一对常驻的「全选」「清空」，各自带禁用态；
- **传输页**：卡头**一枚**会变脸的按钮——列出来的全勾上时显示「清空」，否则显示「全选整库」。于是勾了
  一部分时"清空"在界面上根本不存在，只能一行行点回去，而那正是最想清空的那一刻；
- **迁移页**：这一对只在「只选其中几条」下出现（清单摆着却没有工具），文案是另外两枚键，而且「全选」
  的作用面是**整份候选**而不是眼下列出来的那些——搜索框收窄之后，它会悄悄选上屏幕上看不见的会话。

三处的作用面、禁用判据、文案各写一遍，读的人学到的是"每张清单都要重新找一遍那两个词"。

## Decision

- **一对常驻的按钮**：「全选」与「清空」，共用 `list.selectAll` / `list.clear` 两枚键
  （`transfer.export.selectAll`、`migrate.scope.selectAll`、`migrate.scope.clear` 三枚重复键删掉）。
  不做"会变脸"的那一枚——两枚各自的禁用态已经说明了当下能不能点。
- **作用面**：全选 = **眼下列出来的**那些里能单独勾的（筛过之后就是"这几类都选上"）；清空 = 整个勾选
  集（眼下的勾选可能包含被筛掉的行，所以不是"清掉列出来的那些"）。
- **禁用判据**：全选在"一条能勾的都没有"时禁用，清空在"一条都没勾"时禁用。
- **位置**：清单之上那一行的右端。清单就是整张卡的内容时是卡头（会话页、传输页），清单是卡片里的一段
  时是清单上方那一行（迁移页的勾选）。与
  [卡片动作行](../architecture/2026-10-07-card-actions-live-in-a-footer-row.md) 那条规矩同源：头部只放
  不动数据的工具，而选行工具跟着它选的清单走。
- **一份实现**：勾选状态收进 `sessionList.tsx` 的 `useSessionPicking()`——会话页与传输页原先各写一份
  逐字同形的 `toggle` / `toggleGroup` / `lockOf`（差别只有变量名），现在两页各拿一份同一个 hook 的
  结果；按钮是同一个 `SessionPickTools`。`picked` 由"库里还在的 id"**派生**，传输页原先为此单摆的
  那个清理用 effect 删掉了。
- **迁移页的勾选提示单独一行**（提示是 `p`，工具在下一行的右端）：它与「已选 N」+ 两枚按钮挤在同一行
  时会换行——实测那一列只有 534px，工具被顶到第二行、行高从 30px 变成 62px；提示是一句话，本来也不该
  跟按钮抢同一行。
- **迁移页的行勾选与模式解耦**：复选框只反映勾了什么（不再在「全部」下把所有行画成未勾）；「全选」连带
  切到「只选其中几条」（勾选只在子集下进请求，不切就是屏幕上满勾、实际整来源一起搬）；切回「全部」时
  清掉勾选（那几条不会被发出去）。「已选 N」由清单上方那一行报，不再塞进单选框的标签里。

## Alternatives considered

**保留那一枚会变脸的按钮。** 它省一个按钮的位置，代价落在"勾了一部分"这个最需要清空的时刻：按钮读作
「全选」，而用户要的那个词在界面上不存在。

**把这一对也搬进卡头，让三页像素级一致。** 迁移页那段勾选在表单卡片的中段（源 / 目标目录、标题、几个
开关之后），而卡头是这张表单的抬头：把选行工具挂到几十行之上，等于让"选这些"离开它选的清单。清单之上
的那一行才是它在另外两页里的等价位置。

**统一到"整份候选"（迁移页原来那样）。** 与另外两页的既有口径相反：那两页选的是眼下列出来的那些
（"筛出空白再一键全选就是要删它们"）。筛过之后悄悄选上屏幕上看不见的行，是"点一下按钮改了看不见的
东西"。

**迁移页保留勾选跨模式留存。** 切回「全部」时请求不发 `sessionIds`，留着的那几条不会被发出去；屏幕
满勾而实际整来源一起搬，是界面在替请求说话。

## Consequences

- 三页的按钮、文案、作用面、禁用判据、位置成为一对；`test/client.test.mjs` 按三页 ×（一条没勾 /
  勾了一部分 / 筛空）钉住，另钉迁移页「全部」模式下行照样画成勾上、以及两处位置（卡头 / 清单上方的
  那一行）。
- 迁移页「全部」模式下现在也摆着这一对：点「全选」＝切到「只选其中几条」并勾上列出来的那些。提示句
  `migrate.scope.tickHint` 把"整来源一起搬、不按勾选走"与这条切换路径都写出来。
- **「全选整库」这个写法不再存在**（README 两处跟着改）：它一直是"选列出来的那些"，「整库」是句错话。
- 勾选只在 `useSessionPicking()` 里算一次，"能勾的集合就是单独操作不会被拒的集合"这条判据（见
  [子智能体不能被单独操作](../architecture/2026-09-30-subagents-cannot-be-operated-alone.md)）不再有两份
  实现可以各自漂移。
