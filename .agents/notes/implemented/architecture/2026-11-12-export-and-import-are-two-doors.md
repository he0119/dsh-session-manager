# Agent Note: 导出与导入是两处入口，导出不再有弹窗

Status: implemented

## Problem

「导出 / 导入」那一面弹窗的左半边，是把页面上的列表**又画了一遍**：6 颗筛选标签（全部 / 子智能体 /
  空白 /
已归档 / 未分组 / 活动）、一个搜索框、"按目录分组"与全部收起 / 全部展开、每行一个勾选框、组头一个整组
勾选框、卡头一对「全选 / 清空」。勾选集在上一轮已经整页共用一份（见
[勾选整页一份](2026-11-12-one-selection-for-the-whole-page.md)），于是弹窗里那份清单不但重复，还和外面的
列表操作的是同一批会话——用户在列表里勾完，进弹窗看见的还是同一张表，只是勾选框小一号。

## Decision

拆成两处入口，两者与勾选的关系不同：

- **导出**跟着勾选走：动作行上一枚「导出所选」（`export.action`），按下去就调 `/export` 打包、交给浏览器
  下载，**不弹窗**。它要求勾选（没勾时禁用），因为它导的就是勾中的那些。完成之后页面顶部那条提示报出
  条数、字节与带走的附件对象（缺的那几个也点名）。
- **导入**与勾选无关：底部状态栏一枚「导入…」（`import.entry`），开一个 **640 的窄弹窗**——要导入的包、
  目标目录、取消 / 导入。**目标目录默认填左栏「项目」筛着的那个**（`PanelShare.project` 因此上移到页面
  骨架），可改、可手输。点「导入」只算一份只读计划，逐条列出会写什么，确认才落盘（与删除、迁移、回滚
  同一条分界）。
- **包可以拖进来**：整页是一个落点（`useFileDrop()`，拖着文件时一圈虚线 + 一句"松手就导入这个包"），
  松手就开这一面并已经拿着包；弹窗里那一格自己也是落点。判据只有一个——后缀是 `.dshsess`，一次一个
  （`logic/fileDrop.ts` 的 `chooseBundle()`，三种情形单独测）。

导出的弹窗、`TransferPanel.tsx`、以及只为它存在的分组列表（`SessionGroupHead` / `SessionGroupTools` /
`useGroupCollapse` / `nestSessions`）与它们的样式一起删掉。列表的分组从此只有一处：左栏那棵项目树
（选一个项目 = 整组处理）。

## 量到的

- 导入弹窗在 1600 窗口下 **640×320**，正文 `gap: 16px`，两个字段 + 一对按钮在首屏内；宽度落在确认弹窗
  那一档（`.dsm-dialog`），不再占 1080。
- 状态栏现在有两枚按钮（导入 58×28、备份与回滚（4）113×28）+ 版本（127），1600 下宽裕；**1024 窗口下
  库路径那一格截到 350px**（后面仍是一行 39px，不换行）——路径的全文还在它的悬浮提示与「说明」里。
- 导出一枚按钮从"点开 → 再点导出"变成"点一下就好"：原来两步之间那次弹窗里能看到包里有多大，现在这份
  数字改由完成后的提示说。

## Alternatives considered

- **留一个弹窗、把导出那半换成一张"确认卡"**（条数 / 合计字节 / 按项目分布 + 一枚「导出所选」）：也消除
  重复，但导出本来就不写盘（它只把已有字节打包给浏览器），"为了看一眼再点一次"没有对应的风险在兜。方案
  草图这里量到的是 760 宽，比现在的 640 多一档宽度、多一次点击。
- **导出也留在状态栏**：它与勾选强相关，放在"对勾中的这些做什么"那一行才找得到；导入恰恰相反。
- **导入也放动作行**：那这条行就有了唯一一枚不要求勾选的按钮，与"这一行都是对勾选做的事"冲突，而上一轮
  正是把导出 / 导入当成例外留在那儿才需要一套解释。
- **保留分组列表、只把它做成只读摘要**：写摘要要再写一份"按项目数条数"的渲染，而左栏的项目树已经把
  "哪些目录、各几条"说过了。

## Consequences

- 导出没有"先看一眼包里有什么"的一步；条数与字节在完成后的提示里说，不满意就再导一次（它不写盘）。
- 状态栏从一枚按钮变两枚：1024 窗口下库路径要截断（截图里量到 350px），换行的可能被 `flex-wrap: nowrap`
  挡住，页面高度不变。
- 「导入」那一面成了状态栏里唯一会写盘的入口，与「备份与回滚」并排——两者都是"对整个库做的事"，与勾选
  无关，这一点由位置本身说明。
- 分组列表那套组件与样式一起删了：以后若要按目录分组地勾选，得重新做（左栏的项目树是目前唯一的分组面）。
- 拖放只在有文件拖进来时才接管（`dataTransfer.types` 里有 `Files` 才算）：拖页内的文字、拖选中的作用域
  照旧是浏览器自己的行为。整页那一层在弹窗开着时不接（遮罩挡在前面），导入弹窗开着时由它自己那一格接。
