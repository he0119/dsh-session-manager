# Agent Note: 目录字段是一个值控件，三条改值的路

Status: implemented

## Problem

源目录与目标目录都是**任意绝对路径**：源是「会话日志里那个 `cwd` 字符串」，目标是「你想搬到哪儿，
那个目录可能还没登记过」。

这排除了两种常见写法：只能用下拉框（列表列不全——值可能在候选之外），以及下拉框只负责把路径填进
另一个文本框（那是把命令化装成控件：框里永远显示占位符，看着像没选中，而真正生效的值在别处）。

候选还有第二个维度：它会长到几十条。候选＝已登记工作区 + 库里有会话的目录，工作区一多，原生下拉框
里就只能一行行滚着找——挑选这件事本身（"我记得它叫 dsh-aperture"）比滚这个动作便宜得多。

## Decision

**一个值控件 + 三条改值的路**（值控件**本身是什么**是另一条决策，
[见那篇](2026-10-07-directory-field-picks-from-a-panel.md)——本文管的是这条骨架与候选、筛选的性质）：

- 值控件**自己就是那个值**（文本就是它，不做"选一下、填进别处"），候选＝已登记工作区 **+** 库里真有
  会话的目录（后者带条数——注册表的登记条数会骗人，同一个目录下可能有没登记在册的会话）；
- **当前值永远在候选里**：值可能是「浏览…」选回来的、注册表与会话都没覆盖到的目录，补这一行之后框里
  显示的永远就是将要用的；
- **「手输路径」**是万能兜底：展开一个和下拉框同值的文本框。宿主没有目录选择器、或要在候选之外敲一个
  路径时它是唯一的路，所以它对每个宿主都在，且只换控件不改语义；
- **文件系统那条路**的行为由宿主报来的能力种类决定（见
  [「浏览…」按宿主的能力走](../bug-fix/2026-09-27-browse-follows-the-picker-capability.md)）。

选择器返回值先削掉结尾斜杠（`normalizePickedPath()`）：会话 `cwd` 与注册表路径都不带结尾斜杠，
`/a/b/` 会凭空多出一个「不同的项目目录」，匹配不到任何会话。

候选多了以后，候选列表上还有一个**筛选框**（它挂在哪一份列表上属于上一条决策，这里只说它的判据），
它只把列出来的候选收窄，**不碰值**：

- 筛过之后**当前值那一行仍在**（列表里显示的就是将要用的——筛选词不该把这句保证弄丢）；
- 关键词对**行自己的事实**匹配（路径 / 标题 / 项目身份 / 那一行自带的文案），不对"渲染出来的那一整
  串"匹配：串里拼了「— 3 条会话」这样的装饰，拿它当关键词库会让「3」命中一堆行（`filterPathRows()`）；
- 筛选词只作用于**它自己那个字段**，筛完的顺序仍是候选本来的顺序（注册表顺序在前、有会话的目录按
  路径排在后）——筛一下就让行换位置，用户会以为候选变了；
- 敲字**不改值**（没有"唯一命中就自动选中"）：半句话被当成确认，按「迁移」搬走的就是另一个目录。

## Alternatives considered

**纯下拉框。** 候选列不全，而使用者要搬去的目录常常正是那个不在候选里的。

**下拉框 + 一个独立文本框（下拉只负责填空）。** 框里显示的永远是占位符而生效值在别处——控件在撒谎。

**只留手输框。** 那要求使用者记得住绝对路径，而这份下拉框的候选（含条数）正是本插件比 `ls` 多知道
的那部分信息。

**按容器宽度在两种控件间切换。** 同一个值有两种外观，会让人以为它们是两个设置。

**候选多了也不给筛选（照旧纯下拉框）。** 候选一多，滚动的成本就压过了"从候选里挑"这件事本身；而
下拉框自己的输入即跳转只认**行首**，工作区标题长成什么样、记不记得住，全靠运气。

**值控件到底用哪一枚控件。** 原先是原生下拉框（旁边挂一个筛选框），后来换成了点开的面板：这是另一条
决策，[见那篇](2026-10-07-directory-field-picks-from-a-panel.md)与被它取代的那几条备选。

**输入即选中（唯一命中时自动把值改掉）。** 打字不等于确认：半句话命中一条就改值，用户按「迁移」时
搬走的是另一个目录。

## Consequences

- 「框里显示的就是将要用的」是一条可检查的性质，也是上面第二条候选规则存在的唯一理由；筛选之后它
  仍然成立（当前值那一行一定留着）。
- 这条形状不依赖宿主能力：能力缺失时少一条改值的路，值与语义不变。
- 筛选的匹配判据钉在 `test/planRows.test.ts`（纯函数），"当前值那一行仍在""筛选词只管自己那个字段"
  钉在 `test/client.test.mjs`（产物冒烟）。
