# Agent Note: 页头照内建设置页的规格

Status: implemented

## Problem

官方设置页的页头**没有原语可用**：`dsh-client-ui-settings-plugins`（「插件」那一页）自己手写
`h2` + `p`，用打包哈希的类名（`pbvGtq_section` / `pbvGtq_heading` / `pbvGtq_intro`）写本地 CSS。
那份类名与那个功能插件包都不该复用，所以规格只能**去真实设置页里量**。

这里原先写成 14px 的 `span` 加一行 `row` 布局，一眼就能看出「和内置插件那页不是一套」。

## Decision

照内建设置页的规格写：`h2` 18px/600 的标题独占一行，下面隔 12px 跟一行 13px 的说明行，整体是
`display:flex; flex-direction:column; gap:12px`。说明行的颜色是 `--dsw-alias-label-tertiary`
（浅色主题 **#81858c**，量的就是那一页 `p` 说明行的计算色）。

## 页头里不放动作

页头只有上面那两行，一枚按钮都不放；页面级的那枚「刷新」（`page.refresh`）挂在**页签那一行的右端**
（`.dsm-tabsRow`，页签整排只占左边一段）。量出来的三条：

- 与标题同排时，标题那一行的行高被 30px 的按钮从 24px 撑到 30px，而设置外壳自己那枚「打开配置
  文件」就压在它上面（同一列右对齐的两枚按钮，间隔 34px、右边缘还差 26px）——页头因此读成"两枚
  按钮上下叠着"，而不是"标题 + 说明 + 一排页签"。
- 挪到说明行右端也不行：说明行（`会话库：… · 457 个会话 · 13 个工作区`）实测宽 **497px**，加按钮
  与间距要 **580px**，而内容列只有 **564px**，它会被挤成两行，页头反而从 62px 长到 79px。
- 页签那一行右端量下来空着 **142px**（英文页签整排 421px，内容列 564px），「刷新」71px 放进去不用
  挤任何东西。面板窄到装不下这一排时（英文页签 421px 已经占满）靠 `flex-wrap` 换行，按钮仍留在
  可视区内，不会被挤出面板。

## Alternatives considered

**复用那个功能插件包的类名。** 类名带打包哈希，换一代就变；而且那是另一个包私有的 CSS，复用等于把
自己的版面绑在别人的实现细节上。

**用 `ui-primitives` 里最接近的控件凑。** 页头没有对应原语（这正是它被手写的原因），凑出来的东西
在行高与间距上与相邻的官方页面对不齐。

**按「看起来差不多」定一个值。** 上面那两个数字（18px/600、13px + 12px 间距）是从真实页面量出来的；
凭感觉定就回到了改动前那个「一眼看出不是一套」的状态。

**把「刷新」留在页头，改成图标按钮。** 图标只是让按钮变轻，叠在同一右列里的那两枚按钮还在，标题那
一行也仍旧被撑高；页头里"没有动作"这条规格本身才是要点。

**做成一枚浮在右下角的按钮 / 每次切页自动重读。** 前者的位置离它影响的清单更远；后者会在六个分页
之间反复重扫会话库（`/state` 一次要扫 457 个会话），而写操作之后本来就已经重读过一次。

## Consequences

- 检查面只列到 `label-secondary`（#61666b，比 `label-tertiary` 深一档），所以 `label-tertiary` 进了
  `test/styles.test.mjs` 的例外表并带回落链。
- 规格有两处钉着：`test/styles.test.mjs` 查 `font-size` / `flex-direction` / 说明行的 token，
  `test/client.test.mjs` 查结构（标题必须是 `h2`、说明必须是 `p`、标题与说明都是页头的直接子节点、
  页头里一枚按钮都没有、`page.refresh` 在 `.dsm-tabsRow` 里）。
- 页签那一行的下划线（`.dsm-tabs` 的 `border-bottom`）因此挪到了它外层的 `.dsm-tabsRow` 上：那一行
  现在是「页签 + 右端的刷新」，下划线跟着整行铺满。
