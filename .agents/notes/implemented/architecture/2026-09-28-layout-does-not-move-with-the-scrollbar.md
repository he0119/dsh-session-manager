# Agent Note: 版面不跟着滚动条动

Status: implemented

## Problem

设置弹窗内容区那条滚动条会一进一出，这台机器的 Chrome 滚动条不占位，内容宽度因此变化。凡是把位置
交给容器右边缘的写法，都会跟着平移。

坑出在两处，都是量出来的：

- 「会话」页筛选条末尾那句「多选＝任一命中」起先用 `spacer` 顶到右端，它的位置就等于容器的右边缘，
  滚动条一进一出这句话平移 **9px**（装了占位滚动条的环境是 15px）；改成紧跟胶囊同一行仍然不稳——
  那一行只剩三十来 px 余量，容器再窄一点就整行换行。
- 列表以前是 `max-height`，筛掉行就变矮，整页跟着变矮，外层那条滚动条于是在「有」与「没有」之间切。
  占位滚动条的环境里，它每切一次就把整个卡片的右边缘挪 15px，卡头按钮、行里右对齐的字节与时间全跟着跳。

## Decision

- 那句说明**自己占一行**（`<p>`，在 `.dsm-filters` 后面）：左边固定不动，胶囊那一行的余量也宽出
  九十来 px——同样的刺激下换行阈值从 30px 变成 135px，一次滚动条切换越不过去。
- 列表高度**固定**（`height: min(420px, 42vh)`），「一条都没筛出来」的空态画在那个框**里面**
  （换成框的兄弟就等于把框撤了，高度又变回去）。
- `.dsm-list` 另加 `scrollbar-gutter: stable`。
- 三个分页的列表都是这样，`dsm-listFixed` 一处定义。

## Alternatives considered

**把说明句放在容器右边缘（`margin-left: auto` / `spacer`）。** 那就是让它去追一个会变的边界。

**让滚动条占位（外层恒定 `overflow-y: scroll`）。** 那要改的是设置弹窗的滚动容器，属于外壳的地盘；
而且它对「不占位滚动条的环境」不生效。

**保持 `max-height`，把空态画在框外。** 实测那种情况下高度照样变：35 行 / 5 行 / 1 行三种状态下，
改之前外层滚动条的切换把卡片右边缘挪了 15px。

## Consequences

- 真实 GUI 里量到的：35 行 / 5 行 / 1 行三种状态下列表框都是 242px、卡片都是 608px、外层滚动容器的
  `scrollHeight` 都是 760px——外层滚动条再也不会因为筛选而切换。
- 代价是筛完只剩几行时框里留一块空，这是刻意的。
- 头两条（说明句自己一行、空态画在框里）在 `test/client.test.mjs` 里按**结构**钉住——位置本身在这种
  环境里量不出来，但那两个退化（又挤回那一行、空态又把框撤了）会被抓住。
