# Agent Note: 两级在一眼之内分得开

Status: implemented

## Problem

分组本身只解决了「哪些会话是一批」，没解决「哪一行是工作区、哪一行是会话」。这两件事在同一个列表里
必须一眼分得开，因为**会话标题是用户自己写的第一句话**——它长得像个目录名是常事：本机就有一条叫
「dsh-session-manager 使用说明」的会话，跟组头「dsh-session-manager」并排时，只靠读字是分不出来的。

## Decision

两级的区分叠了**四层**，任何一层失效（换个主题、换块屏幕、色觉不同）都还有别的手段兜住：

| 层 | 组头（工作区） | 会话行 |
|---|---|---|
| 底色 | 字色薄雾 12% 兑在卡片表面上，一条不透明的实心横幅 | 卡片表面色（悬停时才兑 6% 的薄雾） |
| 缩进 | 贴列表左缘 | 整行缩进 26px，左缘一条 2px 导引线逐行相接 |
| 字号 | 14px / 600 | 14px / 400（跟着页面正文那一档） |
| 图形 | 文件夹（`dsm-levelWorkspace`） | 对话气泡（`dsm-levelSession`） |

字号那一档的来源见 [正文与次要文字照内建设置页的两档](2026-10-07-body-type-matches-the-builtin-settings.md)。

组头是 `nowrap` 的一条，右边那两串数字（这组几条 / 选中几条）是**一整块**：让位的必须是路径
（`flex-basis: 0`，先截断，悬浮提示补全），不是折行。

## Alternatives considered

**只靠底色再深一点。** 浅色主题里 `bg-layer-1/2/3` 是**同一个白**，能用的只有「字色兑出来的薄雾」，
而薄雾的可见度本来就依赖屏幕与视力。

**只靠字号。** 字号差一档在有缩进时是辅助，单独用时几乎看不出来——而缩进正是「一眼」这件事的主承重。

**引一个图标包。** 宿主的图标包是打包器哈希过的私有产物；两个轮廓自己内联在
`src/client/components/icons.tsx` 里（`currentColor`，不引图标包、不加资源）。

**让组头折行来容纳长路径。** 本次改之前正是 `wrap`，路径一长数字就被挤到第二行，组头长成两行、数字
跑到左边，看着像坏了（532px 宽的列表里真实发生过）。

## Consequences

- 四层都在 `test/client.test.mjs`（两级各挂各的标记、组头仍是整组勾选的入口、计数块是一整块）与
  `test/styles.test.mjs`（颜色只走 token）里钉着。
- 缩进、字重、图形这三层跟颜色无关，是层次的**主承重**；字号这一层与正文对齐内建那两档之后就
  不再承担区分（两级同号，靠 600 与 400 分开，内建的列表也是这么做的）。
