# Agent Note: 正文与次要文字照内建设置页的两档

Status: implemented

## Problem

内建那几页把字分成**两档**：卡片标题 `<strong>` 是 14px / 500 / 行高 20px，卡片描述是 12px / 400 /
行高 18px（「内置插件」「模型」「Agent 预设」三页在本机两代宿主上量下来同值）。

本页原来是正文 13px、说明句跟着正文一起 13px：整页比内建小一号，而且"这是补充"这件事只剩颜色在说
（次要色），字号上一点差别都没有。本页页头又是照内建量的（16px/500 的标题 + 14px/22px 的说明行），
两者上下挨着，两套尺看得很清楚。

## Decision

正文走 **14px / 行高 20px**（`.dsm-root`），比正文淡一档的字走 **12px / 行高 18px**（`.dsm-hint`）。
行高留在 20px、不按字号比例放大：内建卡片标题就是 14px/20px，行盒高度因此不变，行高与缩进那些量着
调的几何值（组头 38px、组内 26px 的缩进、标签那条 18px 的对齐）才不用跟着重算。

同一批跟着走的显式字号：

| 位置 | 现在 | 依据 |
| --- | --- | --- |
| `.dsm-root`（正文） | 14px / 20px | 内建卡片标题 14px/20px |
| `.dsm-hint`（说明句） | 12px / 18px | 内建卡片描述 12px/18px |
| `.dsm-planHead`（预演弹窗的段头） | 14px / 600 | 段头走正文那一档，与 12px 的说明句差一档 |
| `.dsm-dialogBody`（弹窗正文） | 14px / 20px | 弹窗里摆的就是页面上的组件，两处同规格 |
| `.dsm-dialog .dsm-button`（弹窗按钮） | 14px | 同上 |
| `.dsm-defs`（说明页的词条） | 14px / 22px | 正文那一档 |

**没跟着改的四处**，都在内建页里量到了不同的值，各有理由：

- `.dsm-search` 是 13px / 18px：内建那几页的输入框就是这一档，比正文小一号是输入框自己的规格。
- `.dsm-tag` 是 12px 的方块：内建的标签是 11px / 行高 17px 的胶囊（padding 1px 8px、radius 999px）。
  本页的标签挤在密集行里，行高 18px 是为了与 20px 的名字行对齐（列表与弹窗两处都有这条兜底），换成
  胶囊会动整列的对齐。
- `.dsm-cardTitle` 仍是 600：内建卡片标题是 500，但内建那几张卡片的描述在标题**下面**一行，本页卡片
  的头部是标题、计数、工具横着排在同一行里——真实 dev GUI 里并排看过，500 时标题与紧挨着的计数读起来
  差不多重，卡片就没有锚点了。
- `.dsm-hint` 仍走 `label-secondary`：内建卡片描述是 `label-tertiary`。这一档是页内量过对比度挑的
  （见 [颜色只走检查面的 token](../bug-fix/2026-09-27-token-only-colors.md)），不在这次字号对尺的范围里。

## Alternatives considered

**继续用 13px 的正文。** 那就要接受整页比内建小一号，且说明句与正文同大——"补充"只能靠颜色说，换
主题、换屏幕、色觉不同都会漂。

**只把说明句降到 12px、正文留在 13px。** 层次是对了，整页仍比内建小一号；与本页页头那行 14px 的
说明挨着看还是两套尺。

**整页按比例缩放（正文 14px + 行高跟着放到 22px）。** 行盒变高，组头行、缩进、标签对齐这些量着调的
几何值全部要重算，而内建卡片标题给的就是 14px/20px，没有理由放大。

**连标签一起换成内建的胶囊（11px/17px、radius 999px）。** 那是组件形状的改动，牵动密集行里的对齐与
两处 18px 的兜底规则；字号对尺这一件事不必把它一起带上。

## Consequences

- 两处钉着：`test/styles.test.mjs` 查 `.dsm-root` 与 `.dsm-hint` 的字号与行高；`test/client.test.mjs`
  里"动作页每段说明不超过两行"那条上限按新排版重算了容量（卡片正文宽 534px、说明句 12px，一行约 44
  个汉字 / 87 个字符，两行的容量 88 / 174，两个上限值贴着它）。
- 会话列表那两级的**字号差没了**：组头与会话行现在都是 14px（组头 600 + 主文字色，行 400 + 次要色，
  另有缩进、底板与图形）。这跟内建的做法一致（「插件」整页的组标题 14px/500、行标题 14px/400 也是
  同号不同重），但它动了 [两级在一眼之内分得开](2026-09-27-two-levels-in-one-glance.md) 里"字号"那一
  层，那篇笔记的表已按现在的事实改。
- 说明页的词条从 13px 长到 14px：词条本来就是整页最长的文本（最长一条量到 11 行），这一页的规则是
  "长解释留在这里"，不设行数上限。
- 弹窗里的字号是自己写的（官方 Modal 会 portal 到 `document.body`，落在这套 `.dsm-root` 之外），
  正文与按钮那两条要跟着这一档一起改，否则同一条会话行在弹窗里与页面里长得不一样。
