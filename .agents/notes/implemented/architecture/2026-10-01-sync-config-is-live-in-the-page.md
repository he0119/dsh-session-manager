# Agent Note: 同步配置在页面里就地可改，只有 sync 是活字段

Status: implemented

## Problem

`sync` 那一节填的东西（远端 URL、机器名、映射表）**每台机器都不一样**：装第二台机器时，用户得先找到
配置文件、知道 `mapping` 是「远端 cwd → 本机目录」、还得手写 YAML。填错了不报错，只是预演时一条条
「没配映射」被跳过——现象离原因很远。

插件原本的配置面只有手改文件这一条路，而宿主的设置接缝本来就能读能写那一节：界面里缺的是一张表单。

## Decision

`sync` 那一节带 `volatile`，于是它在宿主手里是**活引用**（Loader 按固定路径就地更新，改完不必重启），
设置接缝把它投影成可编辑的一节；三个路径字段（`sessionsRoot` / `registryPath` / `backupRoot`）刻意不带。

- **读写面**：设置接缝 `configForms.get('session-manager')`（命名空间 = profile 里那个 entry id）。
  读出来的是生效值（用户层 → 组合层 → 默认值），写回去的是**用户层**——也就是设置对话框
  「Open configuration file」打开的那份文档（`~/.dsh/profiles/<name>/cordis.patch.yml`）。插件不另存
  状态文件：配置只有一个来源。
- **表单画在本插件自己的设置页**（「同步」分页的卡片里，与「预演同步 / 确认同步」挨着），没有注册
  宿主的 `plugins.bundle.config` Slot。接缝是命名空间寻址的（谁取都是同一份控制器），放哪一页都不改变
  读写语义；改完 URL 的下一件事就是预演一次，分两页要多一次跳转。
- **映射表是一行一行的**（远端 cwd → 本机目录，可增删）：这一栏真正难的地方不是排版而是**左边那一栏
  必须逐字对上别的机器记下的路径**，所以它带一份候选——上次预演里见过的远端 cwd 直接列出来，抄错一个
  字符的代价是"没配映射，跳过"。空行（点了添加又改主意）不算一条，缺一侧或同一个远端出现两次才挡住
  保存，并且指到行号。
- **保存是显式的，且只提交改动过的字段**：逐字提交会让每次击键都变成一次文档写入；提交没动过的字段会
  在用户层攒下「等于默认值」的覆盖，界面上那些字段从此都顶着「已覆盖」徽标。

## Alternatives considered

- **照官方 `plugins.bundle.config` Slot 画卡片**（同仓的 `dsh-aperture` 走的就是这条）：能用，但同步
  设置与预演/确认就分成两页，而那一层的贡献面（`hooks` 约定、`view: 'page'` 投影）本就是为「插件管理器
  里本插件那一页」设计的。放弃「和官方插件长得一样」，换来「改完立刻能预演」。
- **插件自己存一份状态文件**：配置出现两个真相（文件里的 `sync` 与状态文件），用户改哪一个都只对一半。
- **三个路径字段也做成活字段**：它们在装配期就被算成路径常量（会话库根、注册表、备份目录），热改会
  半生效——一半代码拿旧路径、一半拿新路径。放弃「界面上全都能改」，换来「不会半生效」。
- **映射表用一段文本**（`远端 cwd = 本机目录` 一行一条）：实现最省（官方表单原语的字段规格只有文本与
  数字两种，字典类型没有现成控件），但要求用户先知道语法；抄错一个字符只是"这一条没生效"，而错一行
  会让整个保存被挡住——代价落在用户身上，而省下的只是一点界面代码。
- **映射表填 JSON**：能表达一切，但这一栏是给人填的，不是给机器喂的。

## Consequences

- 配置由 `--patch` 覆盖层提供时，表单能读出值，保存却会被宿主拒绝（实测：同一个 profile 里把这一节写进
  profile 文档就能保存；覆盖层那条路走不通，界面只能报「保存未被接受」）。原因大概率在宿主的
  `configEditor.edit()`：它在 `reconcileProfilePatches()` 之后重新核对 entry 身份，覆盖层提供的那个
  条目可能就此认不出来。这是宿主的行为，本插件不去绕它，只在文档里说清。
- `passwordRef` 是**环境变量名**而不是密码：密码仍然不进配置文档，由宿主凭据服务或 `process.env` 解析。
  表单里那个密码框是只写的（官方控件库的 `SettingsSecretField`），保存时经 `remote.credentials` 写进
  宿主机凭据库；引用名那一栏不在这张表单上（在插件配置里改）。理由与边界见
  [密码只放引用](../feature/2026-10-01-webdav-sync-is-a-transport.md)。
- 界面里改完 URL 不影响**正在跑的那一次**同步，下一次预演/确认才用新值（配置按快照读）。
