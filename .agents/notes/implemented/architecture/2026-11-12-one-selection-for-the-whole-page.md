# Agent Note: 勾选整页一份，备份能一键撤回去

Status: implemented

## Problem

页签去掉之后（见 [去掉页签那篇](2026-11-12-no-page-tabs.md)），页面只剩列表，可是四件配套的小事还停在
旧模型里：

1. **勾选还是两份**：列表用一套 `useSessionPicking()`，导出弹窗里又起一套。勾了 6 条再开「导出 / 导入」，
   导出栏是空的——"选中的带进弹窗"没有真的发生。
2. **后悔要从反面去找**：删除与迁移都先留一份字节级备份，可提示只写"备份在「备份与回滚」里"，用户得
   自己在清单里按时间认出那一份。三处文案替它指路，正是[备份那篇](2026-10-07-backups-are-their-own-page.md)
   记下的老问题。
3. **入口没有份数**：状态栏那枚「备份与回滚」不说到有几份，人不知道点进去有没有东西。
4. **同步状态重启就失忆**：宿主只把上一趟结论放在进程内存里（`web.ts` 的 `lastApply`），重启之后页头
   那枚状态只能说"配没配"，答不了"昨晚那趟成没成"。

## Decision

- **勾选集上移到页面骨架**：`ManagerPanel` 持有一个 `useSessionPicking()`，列表与导出弹窗共用同一个对象
  （`PanelShare.picking`）。TransferPanel 不再自己起状态——于是"勾了 6 条，导出栏里就是这 6 条"是同一份
  数据，不是两次拷贝。关掉弹窗回来，列表里仍是这 6 条。
- **删除 / 迁移的成功提示带「撤销」**：提示带上那次动作留下的 `backupDir`，按钮走 `openBackup(dir)`：
  打开「备份与回滚」，并直接对那一份开回滚确认（`BackupPanel` 的 `focus` 读到清单后按目录找一次）。
  归档这类不留备份的动作不摆它；任何一条新提示都会把上一枚撤销清掉（一份备份只撤刚做的那件事）。
- **状态栏那枚入口带份数**：一次 `/backups` 的目录列举，在挂载、手动刷新、以及任一弹窗关掉之后各读一次；
  0 份或还没读到时只写名字（不画"0 份"）。
- **同步结论落盘**：`<DSH_HOME>/dsh-session-manager/state.json` 里记一条
  `{ sync: { at, ok, pulled, pushed, error? } }`（见 [sync-state.ts](../../../../src/sync-state.ts)），
  `/meta` 的同步那一栏带上 `lastRun`。页头那枚状态按"证据新鲜程度"选句子：这一趟正跑着 → 这一进程里
  刚跑完 → 磁盘上那一条（多久以前 / 失败（多久以前））→ 配置事实（自动推送 / 未配置）。
  "多久以前"是纯函数（[relativeTime.ts](../../../../src/client/logic/relativeTime.ts)），档位单独测。
- **只记手动同步**：自动推送那一轮只推不拉，混进"上次同步"会让"拉 0 条"读成失败；它跑着的结果仍然由
  页面顶上那条横幅说。

## 量到的

- 状态文件就是一条 JSON（`{ sync: { … } }`），写在插件自己那一层目录里，与备份根同一个父目录；写失败
  静默、读不懂当没有——同步本身不因为记不下一句话而失败。
- 备份份数是异步的：页面刚打开时那枚按钮只写名字，`/backups` 回来之后才变成「备份与回滚（3）」
  （dev 实例上 3 份）。

## Alternatives considered

- **导出弹窗里再"把列表的勾选拷一份进去"**：两份状态会漂——用户在导出里取消一条，列表还勾着；改回来
  又要一条同步规则。共用同一个对象没有这个问题。
- **撤销直接调回滚、跳过确认**：会写盘的动作在本仓库一律"一个按钮开一个确认弹窗"（
  [一次确认弹窗](2026-10-03-one-click-confirm-dialog.md)），撤销也不例外——它撤掉的是一次已经写过的动作。
- **把 lastRun 写进插件配置**：配置是用户的东西，每次同步改一遍会在设置页攒出一串"已修改"，而且
  三个路径字段本来就不进设置表单。
- **记在备份根里**：那个目录的名字说的是备份，混进一个 `state.json` 会让"这个目录里有什么"多一种东西。
- **自动推送也记**：见上，只推不拉的那一半与"上次同步"不是一件事。

## Consequences

- 「撤销」只在删除 / 迁移的成功提示里；关掉提示之后仍能从状态栏进清单，按时间找那一份（备份还在）。
- 撤销按钮点下去会关掉提示（`notify(null)`），用户取消回滚时那条提示也回不来了——它本来就是一句过去时。
- 状态文件是插件在 `$DSH_HOME` 里多写的一个小文件；读不出来时界面安静地退回"配没配"那一句。
- 勾选上移让测试夹具里"第一个空数组状态"从 `ManagePanel` 挪到了 `ManagerPanel`：备份清单那几条用例因此
  多垫一个 `[]`，`nulls` 的顺序不变（`undoAt` 排在最后一个 null 状态）。
