# AGENTS.md — Agent Notes

这里是**决策笔记**：代码与文档承载不了的*为什么*，以及*放弃了什么*。每条信息只写一处——笔记写决策
依据与被否决的备选方案，`docs/` 写当前机制与逐文件职责，根 `AGENTS.md` 写每轮都要在上下文里的硬约束。

## 布局与命名

`{lifecycle}/{class}/yyyy-mm-dd-topic-title.md`，两个维度都编码在路径里。

- **生命周期**是笔记的状态，随状态在目录之间移动：
  - `proposed/`：实施前评审的提案，尚未构建（或仅部分构建）。
  - `implemented/`：决策已交付。文件描述**已交付的现实**，并与代码保持同步。
  - `rejected/`：讨论后被否决的提案。仅当它的依据仍能挡住一个诱人且影响重大的错误时保留。
- **类别**是决策的种类（封闭集合，别新建目录）：
  - `feature`：面向使用者或模型的新能力。
  - `bug-fix`：修正缺陷，或补上事故复盘发现的缺口。
  - `simplification`：在**不增加能力**的前提下移除代码、行为或对外范围。
  - `architecture`：关于**交付源码**的结构性决策：模块之间的关系、运行时词汇。
  - `process`：代码**周边**的工具、策略或工作流。
  - `testing`：测试基础设施与策略。
- 文件名里的日期是该主题**首次提出**的时间，以 git 历史为准（`git log -S'<符号或短语>'`）。
  本仓库的历史很短，同一天出现多篇笔记是正常的——不要为了「看起来分散」改日期。
- 笔记之间用相对 Markdown 链接互相引用，链接必须能解析。
- **本仓库还没有 `archived/`**：冻结层与 sha256 manifest 是笔记多到几百篇时的产物，现在没有这个需要。

## 文件格式

每篇笔记的前三行严格为：

```markdown
# Agent Note: <标题>

Status: <状态>
```

后跟一个空行。`Status:` 必须与所在生命周期目录一致：

- `Status: proposed`
- `Status: implemented`
- `Status: rejected — <一句话原因>`

正文以 `## Problem` 开头——动机要写成不依赖解决方案也能独立成立的一段。固定章节用下列名称，真正独特
的技术章节在必需章节之间自由组织：

- `implemented/`：`## Decision`（现在时，描述已交付的现实）→ 自定义 → `## Alternatives
  considered` → `## Consequences`。**禁止**出现 `## Proposal` / `## Plan` /
  `## Migration plan` / `## Acceptance criteria`。
- `proposed/`：`## Proposal` → 自定义 → `## Alternatives considered` →
  `## Acceptance criteria` → `## Risks`。
- `rejected/`：保留提案时的章节，结论写在 `Status:` 行上。

`## Alternatives considered` **必须有**：每个真实的备选方案配一句它为什么落选。记录决策时不记录它
击败了什么，就是在邀请反复争论。

笔记是**中文单语**，没有语言切换栏——README 那一对的双语契约不覆盖笔记。

写在源码 JSDoc 与模块头注释里的判据（例如 `src/client/index.ts` 顶上那条导航图标的说明）**留在源码
里**：读那段代码的人正好需要它，搬家反而让它离读者更远。

## 何时写一篇

只有代码、测试与现有文档都没能解释的决策理由具有长期价值时才写，并与改动同一个提交。

- **豁免**：机械改动、措辞调整、纯局部实现细节。
- **不豁免**：安全边界、默认值、对外契约、文件格式、修掉一个有现象可查的缺陷——规模小不是理由。
- 已有一篇笔记持有该决策就**更新它**，不要新建重复笔记。
- 笔记**永远不被编辑成另一个决策**：用新笔记取代旧笔记，并让两篇互相链接。
- `implemented/` 的笔记跟着代码走：路径、符号、默认值、机制变了就在同一次改动里就地改事实——只改
  事实的表述，不改决策本身。

## 门禁

`test/notes.test.ts`（在 `pnpm test` 里跑）核：路径形状、三行头部、`Status:` 与目录一致、
`## Problem` 是第一个二级标题、必备章节在、禁止章节不在、相对链接可解析。改笔记格式时同一次改动里
改它。
